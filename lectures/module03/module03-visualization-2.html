geom_histogram()

  • Default bins = 30
  • Note that bins is not in aes() since it always a fixed number not related to any data
  • Continuous variable on the x-axis, divided into equally spaced bins.
  • Height of a bar displays the number of observations that fall in each bin.

geom_boxplot()

  • Thick middle line = median; thinner lines: 25%tile and 75%tile; dashed lines = “whiskers” to +/- 1.5*IQR
  • Points beyond 1.5*IQR are given separate dots
  • Theme removes ticks and axis text on the right example. Will learn more in the future.
  • Continuous variable on the y- or x-axis provides visualization, as well as measures of central tendency and spread.

  ggplot2::geom_boxplot()
ggplot2::ggplot(birthwt, aes(x = bwt, y = race, 
                             color = race,

  ggplot2::geom_boxplot(alpha = 0.25, 
                        linewidth = 1)

geom_violin()

  • Violin plots look “similar” to boxplots but identify differences in the distributions
  • Hybrid between a boxplot and density plot.
    • Displays the distribution and probability density of the data.
    • Mirrored and rotated density plot.
  • “Width” of the violin represents frequency of the data points in a given area.
    • Wider sections indicate higher density.

Statistical transformations

  • geom_boxplot(stat = “boxplot”) is the default

Some geoms apply statistical transformations to the supplied data prior to plotting. E.g.,

  • geom_boxplot calculates a five-number summary.
  • geom_bar counts the number of observations per group.
  • geom_smooth fits a regression model and plots its predictions.

Every geom has a default (implicit) stat. Even those that don’t perform transformations (stat = identity).

birthwt |> 
  ggplot2::ggplot(aes(y = bwt, x = smoke)) + 
  ggplot2::geom_boxplot()
birthwt |> 
  ggplot2::ggplot(aes(y = bwt, x = smoke)) + 
  ggplot2::geom_boxplot(stat = "boxplot")

Facets

  • Facets generate multiple small plots each showing different subsets of the data.
  • Helps compare variables based on a conditioning variable.
    • E.g., the relationship between age and birthweight given smoking status and/or race.
  • Conditioning variable must be categorical.
    • Discretize continuous variables.

Types of facets

There are three types of facets:

  • facet_null(): generates a single plot (the default).
  • facet_wrap(): “wraps” a 1d set of panels into 2d.
  • facet_grid(): produces a 2d grid of panels defined by two variables.
    • One variable for rows and one for columns.

We will primary concern ourselves with facet_grid() as it can work for one or two faceting variables.

facet_grid()

  • Formula syntax: facet_grid(rowVar~columnVar)
birthwt |> 
  ggplot2::ggplot(aes(x = lwt, y = bwt) ) + 
  ggplot2::geom_point() + 
  ggplot2::facet_grid(smoke~race) # facet: smoke (row) by race (column)

Position adjustments

Useful for bar plots and histograms:

  • stack: stack overlapping bars on top of each other (default).
  • identity: does nothing to overlapping bars but requires alpha.
    • Helpful for histograms but not bar plots.
  • fill: stack overlapping bars and scale so the top is always at 1.
    • Helpful for bar plots but not histograms.
  • dodge: place overlapping bars side-by-side.

Version for scatterplots when many points overlap:

  • position_nudge(): move points by a fixed offset.
  • position_jitter(): add a little random noise to every position.
  • position_jitterdodge(): dodge points within groups, then add a little random noise.

Position adjustments: Bar charts

Scales

  • Scales control how the aesthetic mappings of variables manifest visually in plots.
    • How a variable is translated into color, size, shape, etc.
  • Every aesthetic has a default scale.
birthwt |> 
  ggplot2::ggplot(
    aes(x = lwt, y = bwt)
    ) +
  ggplot2::geom_point(
    aes(color = smoke)
    ) +
  # ggplot adds by default:
  ggplot2::scale_x_continuous() + # x-axis
  ggplot2::scale_y_continuous() + # y-axis
  ggplot2::scale_color_discrete() # color

Overriding default scales

  • ggplot2 has syntax to override default scales.
  • General naming scheme: `scales_‘aesthetic’_‘scale’.
    • breaks and labels are the main arguments used.
birthwt |> 
  ggplot(aes(x = lwt, y = bwt) ) +
  geom_point(aes(color = smoke) ) + 
  scale_x_continuous(
    breaks = seq(50, 250, by = 25) 
    ) + 
  scale_y_continuous(
    breaks = seq(500, 5500, by = 500) 
    ) + 
  scale_color_discrete(
    labels = c("Smoker" = "Current smoker", 
               "Nonsmoker" = "Current nonsmoker"))

Saving plots

  • Once you’ve made a plot, you may want to save it to share with others or to include in a paper or presentation.
ggplot2::ggsave(filename = here::here("output/YYYYMMDD_module03-birthwt-violinPlot.pdf"), 
                plot = violinPlot.bwt.race, 
                height = 6, 
                width = 12)
  • File name conventions should be used (informative and dated).
  • If plot is not specified, the most recent plot displayed is saved.
  • If height and width aren’t specified, the dimensions of the current plot are used.
    • Aspect ratios (width:height) of 2:1 or 4:3 are preferred.
  • Saving to .pdf gives the highest resolution.
    • Although other file types are support (.png, .jpeg).

Why visualize?

  • Summarizing data is fundamental to statistics.
  • Numeric summaries (mean, variance, correlation, etc.) are common and informative.
  • Pairing numeric summaries with data visualizations provides deeper insights, some that may be missed by numerical analysis alone.
